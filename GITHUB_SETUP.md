# Repositório oficial

**[DanBar1971/Remote-PhotoBridge](https://github.com/DanBar1971/Remote-PhotoBridge)**

O código-fonte é publicado no repositório, com um workflow em `.github/workflows/android-apk.yml` que compila o APK de testes.

## Obter APK

Abrir **Actions > Build Android APK**, escolher a execução mais recente com sucesso e descarregar o artefacto **Remote-PhotoBridge-v1.0.0-alpha1-debug**. O APK é experimental e usa assinatura debug (não contém chave de release estável).
